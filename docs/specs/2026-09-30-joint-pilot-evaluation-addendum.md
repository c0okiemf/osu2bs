# Prefit evaluation details

This addendum completes the existing pilot spec before the first optimizer update.
The original spec/data identity remains immutable.

Validation has no cached B0 map for every family. Use empty walls/bombs, NJS18,
and the median requested hand-event rate of the 316 fit families. These are
fixed generation inputs independent of each validation target. The reference is
used only after rollout. Development still uses the cached B0 rate/environment.
This validation-to-development environment/workload shift is a stated limitation.

Missing geometry is unknown, not zero error. Snapshot error is infinite if either
axis is wholly unavailable; retain every component's support count. The positive
pilot gate additionally requires the learned arm's total paired opportunity
coverage on each component to be no lower than each comparator. Thus removing
heads/doubles cannot earn a positive decision through reduced measurement support.

Controls: a low-vertical authored-style fixture self-compares at zero; silence
changes rhythm and removes geometry coverage; shifting events away from synthetic
onset peaks lowers audio alignment; deterministically shuffling geometry while
preserving event times changes geometry with identical rhythm. These validate
arithmetic and sensitivity, not musical taste. Freeze controls, normalization,
training-family retrieval bank, generation code and this addendum before fitting.
Execution orchestration may be completed afterward without changing those rules.

For a failed rollout, retain its literal emitted prefix as a failed artifact;
never evaluate it as a complete chart. Empty prefixes have no chart. Every completed
output is exported and measured from serialized readback. Step0 winning validation
means no learned candidate; run its fixed development diagnostic attempts anyway,
with the positive gate forced false. This preserves the promised complete panel.
