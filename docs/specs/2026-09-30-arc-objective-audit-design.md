# Audit the arc-dominated objective before another geometry fit

The conditional hand-state model improves four
validation geometry components over its fixed control and worsens the arc term,
which dominates its failed aggregate. Native-phase refinement similarly misses
the whole-map margin despite unchanged directional continuity. Preserve every
historical result. Do not spend another fit simply pursuing this proxy.

## Saved evidence and fixed diagnostic controls

Use audited selected exports' saved profiles for the eight opened development
families (B0, original R, native, typed, exact-cut and phase) and the six opened
validation families (fixed phase control and selected conditional model, both
seeds). Recompute their original errors with their original scales. Report arc's
contribution and the other four components separately, without reweighting gates.

On each saved profile, replace only finite arc-descriptor values with zero and
recompute the original error. Preserve unknowns and every other value. This is a
**descriptor counterfactual, not a generated chart or valid candidate**. It tests
what the objective rewards; it cannot earn a gate pass or a quality claim.

Measure human arc sparsity on the existing336 training families and approved45
subset: median, nonzero prevalence and mean, pooled and by fixed event-rate bins
[0,1),[1,2),[2,4),[4,infinity) per second. Report mean absolute loss of a constant
zero prediction and of two independent draws from the same observed marginal.
The latter preserves the human marginal but has no claimed temporal/musical
alignment. This is an arithmetic null, not a sampling policy or quality label.
Use the exact empirical pairwise formula, not a fitted model or random search.

Also report one-dimensional Wasserstein distance between paired-supported arc
marginals, with the same frozen scale. This is an alternative-aggregation
diagnostic only: it ignores placement in the music and does not replace a gate.
Reuse the existing all-up/alternating synthetic control demonstrating that the
five descriptors alone cannot distinguish scoped directional continuity.

## Human-variant evidence, with strict alignment

Metadata already identifies ten training-role families with multiple ExpertPlus
chart hashes. Freeze every corresponding local chart/Info/audio path/hash before
reading new note geometry. Retain missing, changed or unsupported entries.
Use the existing strict authored-binding/source reader; never rename to manufacture
a binding. Compare only supported, literally distinct geometry with byte-identical
audio within a family. Deduplicate literal-geometry aliases. Change beat units only
for physical-time alignment, using native audio duration. No approximate audio
matching or outcome-driven substitution in this audit.

These are human-authored alternatives with unknown preference quality, not new
positive quality labels. Report their original pointwise and marginal arc distances
and the zero-arc descriptor counterfactual, in both reference directions. If no
aligned pair qualifies, say so; do not weaken source support to create one.

## Decision boundary

Freeze code/spec, metadata inventory, saved records/reports/audits/scales, raw variant
sources and protected production files. Tests cover missing support, exact pairwise
loss arithmetic and reordered marginals. Repeat the full report and verify all
historical artifacts unchanged. No fitting, generation, QA-cache writes, new test
families, dependencies, annotations, playtests, judge batches or promotion.

The output is an objective-scope diagnosis, not a retrospective candidate acceptance.
If it exposes a measurement problem, plan a separate validated quality contract
that includes directional continuity, temporal structure and explicit pattern
preferences before further optimization. Do not relabel old negatives, silently
lower margins or declare a distribution match sufficient for good flow.
